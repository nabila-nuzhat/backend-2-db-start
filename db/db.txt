- Vector: 
        - (Vector NoSQL db vs Tradotional NoSQL db -googless)
        
        - newer, highly specialized type of NoSQL database.

        - (Note: Traditional database brands like MongoDB, PostgreSQL, and Redis have also recently added "vector search" features to their existing systems so they can handle this data type too).    

        - Traditional NoSQL databases (like Document or Key-Value stores) look for exact matches. They ask the database: "Does user ID 123 exist?" or "Find all posts where the tag is exactly 'Tech'".Vector databases do not do exact matching. They use complex geometry to perform Approximate Nearest Neighbor (ANN) search. They ask the database: "Find the top 5 images that look conceptually similar to this drawing". Standard NoSQL architectures were never designed to run high-dimensional geometric math natively.
